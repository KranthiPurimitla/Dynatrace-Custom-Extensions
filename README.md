# Dynatrace Custom Extensions

Collection of Dynatrace Extension 2.0 custom extensions, one folder per extension, grouped by the framework they use. Each extension has its own folder per released version, for example `Python/VeloCloud/4.0.0/`.

## Python data source

Extensions built on the Python data source (`dynatrace-extension` SDK).

| Extension | Folder | Description |
|-----------|--------|-------------|
| VeloCloud SD-WAN | [Python/VeloCloud/4.0.0/](Python/VeloCloud/4.0.0/) | Edge, link, and health metrics from the VeloCloud API |
| Genesys Cloud | [Python/GenesysCloud/0.0.3/](Python/GenesysCloud/0.0.3/) | Conversation and platform health metrics from the Genesys Cloud API |
| Pure Storage (Pure1) | [Python/PureExtension/1.0.0/](Python/PureExtension/1.0.0/) | Per-volume capacity metrics from the Pure1 REST API, used for volume utilization alerts |
| NetApp Custom | [Python/NetAppCustom/2.0.0/](Python/NetAppCustom/2.0.0/) | NetApp custom metrics using the Python data source |
