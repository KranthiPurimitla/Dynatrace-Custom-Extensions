# Dynatrace Custom Extensions

Collection of Dynatrace Extension 2.0 custom extensions, one folder per extension.

| Extension | Folder | Description |
|-----------|--------|-------------|
| VeloCloud SD-WAN | [VeloCloud/4.0.0/](VeloCloud/4.0.0/) | Edge, link, and health metrics from the VeloCloud API |
| Genesys Cloud | [GenesysCloud/0.0.3/](GenesysCloud/0.0.3/) | Conversation and platform health metrics from the Genesys Cloud API |
